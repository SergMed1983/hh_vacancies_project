# Парсер вакансий с hh.ru (Проект 3)

Программа собирает данные о компаниях и вакансиях с сайта hh.ru, сохраняет их в PostgreSQL и предоставляет аналитику через консольный интерфейс.

## 🚀 Функционал
- Автоматическое создание БД и таблиц (`employers`, `vacancies`) со связью `FK`.
- Парсинг данных с hh.ru (с фоллбэком на локальный JSON).
- Класс `DBManager` для аналитики:
  - Список компаний и количество вакансий (через `JOIN`).
  - Все вакансии с зарплатами и ссылками (`JOIN`).
  - Средняя зарплата (`AVG`).
  - Вакансии с зарплатой выше средней (`WHERE` + подзапрос).
  - Поиск вакансий по ключевому слову (`ILIKE`).
